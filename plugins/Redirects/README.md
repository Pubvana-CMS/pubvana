# Redirects

URL redirect manager with automatic tracking of incoming 404s. Manage 301/302 redirects under **Tools → URL Manager** and review unresolved 404 hits under **Tools → 404 Manager**.

## Features

- 301 and 302 redirects with exact-path matching
- Query strings preserved when forwarding
- Automatic 404 tracking grouped by path
- Triage 404s into redirects, ignore them, or delete them
- Admin and API traffic never redirected or logged
- Anti-scan seed redirects included

## Usage

Open **Tools → URL Manager** to add, edit, and delete redirects. Open **Tools → 404 Manager** to review unresolved 404 hits and turn them into redirects.
