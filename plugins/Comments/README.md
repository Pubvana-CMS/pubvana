# Comments

Nested, moderated comments for your content. Visitors can reply in threads, and you approve or reject each one before it goes live.

## Features

- Nested threads with replies
- Moderation queue: approve, reject, or delete comments
- Guest posting, switchable on or off
- Captcha on the comment form, controlled from the site-wide captcha settings
- Recent comments block

## Usage

Manage comments under **Content → Comments**. Approving, rejecting, and deleting requires the comments.moderate permission.
