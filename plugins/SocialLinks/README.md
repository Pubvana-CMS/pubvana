# Social Links

Central management of your site's social profile links, rendered anywhere on the public site as a block with Font Awesome 7 Free icons.

## Features

- One place to hold every social profile link: Facebook, X, Instagram, YouTube, LinkedIn, TikTok, and ~35 more brands
- Optional custom links with your own label and Font Awesome class
- Enable or disable each link, and reorder with up/down controls
- A public "Social Links" block with an optional title, placed in any region
- Icons are self-hosted Font Awesome 7 Free (no external CDN)

## Usage

Open **Settings → Social Links** to add and manage your links. Place the "Social Links" block in any region to show them on your site.
