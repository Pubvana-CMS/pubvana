# Site Health

Site health and diagnostics for Pubvana. Surfaces configuration and security problems early so you can fix issues before they become incidents. Available under **Tools → Reports → Site Health**.

## Features

- 14 built-in checks across environment, security, configuration, and plugins
- Each check reports Critical, Warning, or Pass
- One failing check does not stop the rest
- Remediation guidance for every failing check
- Dashboard card when issues exist
- Extensible: other plugins can register their own checks

## Usage

Open **Tools → Reports → Site Health** to review all checks and their remediation. Use **Re-run Checks** to force a fresh pass.
