# Media

The media library for Pubvana. Upload images and videos, edit them in the browser, and embed them in your content.

## Features

- Upload images and videos
- In-browser image editor (crop, rotate, sharpen, brightness, contrast)
- WebP derivatives for fast loading
- Video posters
- YouTube and Vimeo embeds
- Media picker for featured images and avatars
- Avatar uploads for admin and public profile editors
- EXIF data is stripped on upload

## Usage

Open **Content → Media** to manage your library. Upload files, edit images, and copy embed codes into your content.

Managing the library requires the media.manage permission.
