# Marketplace

The companion app for the Pubvana Digital Store. Browse the catalog, buy on pubvanacms.com, then verify and install what you bought on this site. No payments happen here.

## Features

- Connect a Pubvana account
- Browse the store catalog with tabs for plugins, themes, and sale items, plus search and paging
- Add items to your cart by update tier: patch, minor, or major
- Checkout on pubvanacms.com, then install here
- Assign a purchase to this site, then install it or reinstall any covered release, after a backup
- Reinstall every owned, licensed item at once
- Feeds update availability to the Updates plugin
- A package the trust service marks malicious is refused before it is copied into place

## Usage

Open **Tools → Marketplace**. Connect your Pubvana account, browse the catalog, and purchase on pubvanacms.com. Purchases appear under **Tools → Marketplace → Purchases** to assign, install, and reinstall.

Managing the Marketplace requires the marketplace.manage permission.
