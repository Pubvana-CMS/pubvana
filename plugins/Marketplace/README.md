# Marketplace

The companion app for the Pubvana Digital Store. Browse the catalog, buy on pubvanacms.com, then verify and install what you bought on this site. No payments happen here.

## Features

- Connect a Pubvana account
- Browse the store catalog and add items to your cart
- Purchase on pubvanacms.com, then install here
- Reinstall every owned, licensed item at once
- Move a license to a new domain
- Feeds update availability to the Updates plugin

## Usage

Open **Tools → Marketplace**. Connect your Pubvana account, browse the catalog, and purchase on pubvanacms.com. Purchases appear under **Tools → Marketplace → Purchases** for install.

Managing the Marketplace requires the marketplace.manage permission.
