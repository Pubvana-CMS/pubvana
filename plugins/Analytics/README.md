# Analytics

Traffic reports for your site: total views, top content, and referrers. Find them under **Tools → Reports → Analytics**.

## Features

- Total views for the selected period, with the change against the period before it
- Visitors and robots as their own lines on the chart
- Views over time, with a 7d / 30d / 90d / 180d / 1y / All range filter
- Top content, ranked by hits, with a link to each path
- Top referrers by domain, with Direct traffic as its own row
- View all for the content and referrer lists
- No IP or location tracking

## Usage

Open **Tools → Reports → Analytics**. Pick a range from the filter to redraw the chart and tables. The Visitors line counts people, the Robots line counts bot hits. Each list has a **View all** link that opens the full list, 100 rows to a page.

A view with no referrer shows as Direct in the referrer list. The Total Views card shows the change against the period of equal length before the selected range.

Page views are recorded for every public page while the plugin is enabled. Individual hits are kept for 30 days, then consolidated once a day.
