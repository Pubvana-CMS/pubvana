# Search

Site-wide search for Pubvana. Content plugins register themselves as search sources, and you turn each source on or off in the admin.

## Features

- Site-wide search across all content plugins
- Ranked results with highlighted terms
- Toggle each content source on or off
- Search form block for any theme region
- Paginated results

## Usage

Open **Content → Search** to manage sources and settings. The public search page is at `/search?q=term`.
